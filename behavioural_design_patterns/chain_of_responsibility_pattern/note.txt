• Decoupling: The sender of a request does not need to know which specific object will ultimately handle it.
• Single Responsibility Principle: Each handler class focuses on one specific rule or task.
• Open/Closed Principle: You can add, remove, or reorder handlers dynamically without modifying existing handler code or the client.
• Flexibility: It avoids massive if-else or switch conditional statements that grow messy over time.
